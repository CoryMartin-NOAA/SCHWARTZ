## Toolbox

### Atmospheric Tools
- **grib2_to_fv3_regrid.py**: Regrid GRIB2 aerosol data to FV3 cube sphere tiles
  - Horizontal interpolation to FV3 cube sphere grid
  - Vertical interpolation using ak/bk model coordinates
  - Support for orography-based corrections
